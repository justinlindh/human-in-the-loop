The engine half of `blender/checks/clip.mjs`, which calls it for every group but `sky`; run it directly for a group's numbers without the check cache or any browser. The page functions in `blender/checks/clip-pages.js` (the ones a harness page plays) run on a Node scene from the studio engine: no Vite server, browser, GPU or render slot. Each group (`pets robot seats perks dance walk props y2k pairs use party garage celebrations respond control`; default all) runs in its own process, `--jobs` at a time (default an eighth of the cores), so no group starts from another's state; the garage group plays the garage mock, the rest the floor. `--rig` plays with the authored clips on, as `clip.mjs --rig` does. It prints the same `CLIP ok|FAIL <name> {...}` lines and exits 1 if any case fails, or names a group whose process ended without results. `sky` reads pixels back from a 2D canvas the engine does not paint, so it is refused here and stays a browser case. A page function needs only what a harness page gives it (`window.__hitlRender`, `__HITL`, `__tick`, `__tool`, the steppers and imports by site path); one that reaches for something else fails here with an error naming it.

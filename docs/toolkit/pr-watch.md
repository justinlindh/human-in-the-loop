A Claude Code mod (function hooks) that follows a pull request from push to merge, in place of `scripts/wait-for.sh <pr> --merged` run in the background. The model calls the tool `mcp__pr-watch__watch_pr` with the PR number (and `cwd`, the worktree that has the PR's branch checked out; default the session directory). The mod keeps the watch in the session's state, so it survives pushes, new heads, a hot reload and a long wait, and polls every minute by running `scripts/wait-for.sh <pr> --merged --timeout 0 --poll 1`, which is one look: the same reading of GitHub state, and the same merge of `origin/main` into the branch (tests, then push) when the PR is behind, as `wait-for.sh`; nothing is forked. It wakes the session (a prompt of its own) only on: a merge or a close without merging (the watch then ends); a failed check; a review verdict on the current head; a merge conflict with main, failed tests after merging main, or a worktree it cannot update from. Each fact wakes once per head. A failed check comes with the failing step: for `local-ci`, the Local CI comment's failing rows (a failure that ran exactly the step limit, 600, 900 or 1200 s, is flagged as a `ci-rerun` candidate, and a machine error says so) and the tail of the kept log in `~/.cache/hitl-ci/failed/pr<n>-<head7>/<step>.log`; for a GitHub check, its job's annotations and the tail of the failed log. Three failed looks in a row (gh down, a bad worktree) are mentioned once. A worktree on another branch than the PR's is watched without branch updates, and the tool says so. `unwatch_pr(number)` stops a watch.

Loading: it is a plugin folder. `claude --plugin-dir scripts/tools/mods/pr-watch` loads it for one session; `CLAUDE_CODE_PLUGIN_DIRS` (absolute paths, `~` allowed, in the process environment or the `env` block of `~/.claude/settings.json`) loads it wherever no flag can be given. The mod's tests are `claude plugin test scripts/tools/mods/pr-watch` (the pure logic) and `tests/tools/mods-pr-watch.test.js` (the hooks against a fake engine, run by `npm test`); `claude plugin validate scripts/tools/mods/pr-watch` checks the manifest and the calls it makes.

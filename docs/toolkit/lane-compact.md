Context resets for teammates running in tmux panes. `hitl-reset.sh` finds the teammate's pane by the `@<name>` in its status bar, waits until the pane is idle (up to `max-wait-seconds`, default 1800), types `/compact` or `/clear`, confirms a compact by the new `compact_boundary` record in the teammate's transcript (a clear writes nothing until the next message, so it waits a few seconds and trusts it), and appends a row to `<memory>/reset-trial.log` (time, name, mode, the context size before, the transcript). It picks the newest transcript from the last day that opens with the teammate's brief (`You are \`<name>\``); `--exclude <prefix>` (or `HITL_RESET_EXCLUDE`) skips transcript files whose name starts with the prefix, such as the caller's own session. After a clear the lead has to resend the brief. Exit 0 done, 1 pane or transcript not found, still busy, or not confirmed, 2 bad arguments.

`hitl-autocompact.sh` is the safe version for a teammate that just said "handoff ready". It holds with exit 3 and the reason on stdout when the teammate's team inbox has unread messages (someone is mid-conversation with it) or when one of its PRs has changes requested (head `<name>/...`; the integrator's are `integ/...`). Otherwise it runs `hitl-reset.sh <name> compact 60` and types a prompt asking the lane to re-read its handoff and restate its paths, open work and open threads, so the lead can check nothing dropped. `--check` stops after the gates and prints `gates pass for <name>; other handoffs naming it: ...`, which names the other lanes whose handoff mentions it, for the open-threads check. The team is the newest `session-*` directory whose `config.json` lists the name; none lists it: exit 1.

Where things live comes from the environment, not the scripts: the memory directory is `--memory`, else `HITL_MEMORY_DIR`, else `<config>/projects/<the main checkout's path with / and . as ->/memory` (`<config>` is `CLAUDE_CONFIG_DIR`, default `~/.claude`), with the handoffs in its `handoffs/` folder and the transcripts in its parent; the teams directory is `--teams`, else `HITL_TEAMS_DIR`, else `<config>/teams`. Needs `tmux`, `jq` and, for the changes-requested gate, `gh` run from the repository. `scripts/tools/hitl-lanes.test.sh` runs both against stand-in `tmux` and `gh`.

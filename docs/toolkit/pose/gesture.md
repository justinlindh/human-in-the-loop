Standalone pose checks from geometry, with no rendering: plays one character through an animation, or a gesture over one (the facepalm over `typing`), and measures every frame in well under a second: each hand's distance to the face, the whole head and the top of the head (metres, hand centre to surface), and the face's angle to the game camera for any view. Prints a row every few frames and a summary over the gesture; `--expect 'hand0Face<=0.05@0.8'` holds a measure to a bound on a share of the gesture's frames and exits 1 when one fails. `--json` also carries a `joints` object on every frame: world positions for every named pivot the character rig has (`hips`, `torso`, `neck`, `head`, `legL`, `legR`, `armL`, `armR`, `wristL`, `wristR`, from `character.js`'s `joints()`), not just the four `probe()` fields (`eyes`, `forward`, `head`, `hands`) the printed table and `--expect` rules use. `--rig off` plays the procedural poses Low quality uses (the default plays the authored clips, as Medium and High do). `--root <worktree>` measures another checkout's render code with this tool, so a pose can be tuned in a lane's worktree before its PR. It runs the game's own character code in Node on the studio engine (`scripts/studio/platform.mjs` and `loader.mjs`: a canvas that draws nothing, fetch reading `public/`, a frame clock, seeded `Math.random`, native imports with `--param` applied as modules load, no Vite); `--check-browser` runs the same measures in a harness page and compares every number; the page serves the checkout the tool runs from, so it refuses `--root` (run the tool from that worktree instead). It needs `three-mesh-bvh`: after merging main, run `npm ci` if it can't be found. Tune a pose on these numbers, and render once at the end. `--scene` measures people in a staged scene instead (a mock with `--patch-js`/`--event`, an indexed `--moment`, or a `--snapshot`): per person and sampled frame, head-rectangle coverage by labels or emotes, facial landmark visibility, body visibility, face angle and projected head height. Its rules use `faceCovered`, `faceVisible`, `bodyVisible`, `faceCam` and `facePx`, for every person or one (`'s3:faceCovered<=0.1@0.8'`). It takes a render slot and draws nothing: warmup and sampling both run every real frame update through `R.render(dt, { draw: false })`, including camera, effects, matrices, CSS label projection and layout. `--render-reference` draws every frame instead, for comparison. Name the people you care about with `--who` to limit visibility rays.

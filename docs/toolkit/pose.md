Pose checks from geometry, with no rendering: plays one character through an animation, or a gesture over one (the facepalm over `typing`), and measures every frame in well under a second: each hand's distance to the face, the whole head and the top of the head (metres, hand centre to surface), and the face's angle to the game camera for any view. Prints a row every few frames and a summary over the gesture; `--expect 'hand0Face<=0.05@0.8'` holds a measure to a bound on a share of the gesture's frames and exits 1 when one fails. `--rig off` plays the procedural poses Low quality uses (the default plays the authored clips, as Medium and High do). `--root <worktree>` measures another checkout's render code with this tool, so a pose can be tuned in a lane's worktree before its PR. It runs the game's own character code in Node with two stand-ins (a canvas that draws nothing, fetch reading `public/`); `--check-browser` runs the same measures in a harness page and compares every number; the page serves the checkout the tool runs from, so it refuses `--root` (run the tool from that worktree instead). It needs `three-mesh-bvh`: after merging main, run `npm ci` if it can't be found. Tune a pose on these numbers, and render once at the end.

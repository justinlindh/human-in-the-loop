# Scripts that are modules or data for the tools, not tools themselves, so they need no toolkit
# entry. One path per line, then what uses it. `npm run toolkit -- --check` reads this.
blender/checks/harness.mjs        the page every render check runs in
blender/checks/panels.js          the visible-panel reader play.mjs and onscreen.mjs share
blender/checks/report.mjs         the report format stage.mjs and the sweep share
blender/checks/diag.mjs           failure detail shared by loop.mjs and clip.mjs
scripts/events/lib.js             the event index's location and key, for build.js and find.js
scripts/events/load.js            opens a page at an indexed moment, for the tools' --moment flags
scripts/perf/stats.js             helpers shared by the perf scripts
scripts/trailer/cards.js          the trailer build's title cards
scripts/trailer/config.js         the trailer build's settings
blender/checks/pose-matrix.js         the pose matrix (pose.mjs --matrix): cells, rules and the grids
blender/checks/pose-matrix-sweep.js   pose.mjs --matrix with --sweep: the matrix once per param value
blender/checks/pose-crop.mjs          one picture of a pose-matrix cell, run by pose.mjs --crop
scripts/trailer/manifest.js       the trailer build's shot list
scripts/hooks/claude/test.sh      the Claude Code hooks' own tests
blender/checks/dump.js            the in-page half of dump.mjs
blender/checks/intersect.js       the sweep's in-page measurements
blender/checks/sample.js          the sweep's in-page state sampler
blender/checks/bvh.js             three-mesh-bvh by package name, for harness pages
blender/checks/clip-exact.js      the clip check's exact triangle-crossing measure
blender/checks/clip-groups.mjs    which clip groups run on which page, and the empty-group check

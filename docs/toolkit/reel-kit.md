The reel effects kit: named presets a reel script sources and calls, such as title, end and lower-third cards, a corner label, trims, hard cuts, crossfades and a speed ramp. Camera moves (push-in, pull-out, pan) happen in the render through a capture item's `camera` keyframes; the kit's 2D push-in is the fallback for a flat frame only. `docs/reels.md` says when to use each preset.

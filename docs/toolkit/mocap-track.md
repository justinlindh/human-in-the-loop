The tracking stage of the motion pipeline (#1397, #1404): a local video range in, one JSON per shot out. The runner finds cuts (ffmpeg scene score, `--cut-threshold`, default 0.4), cuts each shot of at least `--min-shot` frames (default 12) to its own clip and runs the GPU worker on it under `scripts/with-render-lock.sh --gpu`, niced, with a timeout (`--timeout`, default 1800 s per shot). `--no-lock` skips the lock (CPU stubs only). Results are cached per (video hash, shot range, model versions, camera on or off) in `HITL_MOCAP_CACHE` (default `~/.cache/hitl-ci/mocap-cache`); a second run of the same range prints `from cache` and starts no GPU job, `--no-cache` forces a rerun. Ctrl-C stops the worker's process group and removes the scratch directory (exit 130).

Output: `<out>/index.json` (video hash, fps, size, range, the shots with `cache: hit|miss` and person counts, skipped short shots; never a file path) and `<out>/shot-<n>.json`, schema `hitl-mocap-shot` version 1:
- `joints`, `parents`: the 77 SOMA joints (Hips first) and each one's parent index.
- per person: `id` (ByteTrack id, stable inside the shot), `observed` (per frame, 1 when the detector saw the person, 0 for a gap filled by interpolation), `rot_local` (T x 77 x 4 quaternions [x, y, z, w], each local to its parent; joint 0 is the world root orientation), `root_orient_cam`, `root_pos_cam` (camera space metres), `root_pos_scene` (the root placed in one scene frame shared by every person in the shot, through the camera path), `joint_pos_world` (per person, each starting at its own origin, so use `root_pos_scene` to place people relative to each other) (T x 77 x 3 metres, y up), `trust` (T x 77, 1 when the RTMPose-x 2D gate supports the joint, others inherit from the nearest gated ancestor).
- `camera`: Depth Anything 3 Base world-to-camera `w2c` (T x 3 x 4) and full-resolution `intrinsics`, which also drive GEM-X's world placement in place of its static camera fallback. DA3's scale is relative: `scale_to_metres` (GEM's person depth over DA3's depth at the person's root pixel, median over frames) converts its translations, and `root_pos_scene` is already in metres. `--no-camera` uses a static camera and `source: static`.
- `models`: the pinned versions the result came from; they are part of the cache key.

Setup builds everything outside the repo in `HITL_MOCAP_HOME` (default `~/.cache/hitl-mocap`): a uv venv, the pinned GEM-X checkout with its SOMA and SAM-3D-Body submodules, a one-line SOMA patch for newer torch, Depth Anything 3, rtmlib, onnxruntime-gpu, the CUDA torch pair (`HITL_MOCAP_TORCH`, default from `models.json`; it has to match the CUDA toolkit `nvcc` reports) and the model weights. Re-running skips finished steps. Licences: GEM-X weights are under the NVIDIA Open Model License, SAM-3D-Body under Meta's SAM License, DA3 Base under Apache-2.0; weights stay out of the repo.

Tests use a synthetic clip and a stub worker (`tests/tools/mocap-stub-worker.mjs`); the reference footage never enters the repo, an issue or a PR.
